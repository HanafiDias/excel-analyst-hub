HR & Operations Excel / Time Functions

Otomatisasi Laporan Kehadiran & Kalkulasi Lembur

Mengubah proses manual 3 hari menjadi perhitungan otomatis kurang dari 15 menit menggunakan logika Time Intelligence.

1. Latar Belakang & Masalah Bisnis

HRD perusahaan manufaktur skala menengah harus merekap log kehadiran dari mesin fingerprint setiap akhir bulan. Proses ini memakan waktu 2–3 hari kerja penuh karena:

  • Data mesin diekspor dalam format CSV mentah tanpa label nama karyawan.
  • Aturan lembur berbeda antara shift pagi (07.00) dan shift siang (14.00).
  • Denda keterlambatan dihitung progresif (makin terlambat, makin besar dendanya).

Satu kesalahan kecil dalam hitungan manual bisa berujung pada komplain penggajian dari karyawan dan revisi laporan yang menyita waktu manajer.

2. Arsitektur Formula (Time Intelligence)

Menghitung waktu di Excel sangat rawan error karena format sistem 24 jam. Saya merancang sistem yang mendeteksi jam masuk karyawan (In) dan jam pulang (Out) lalu menghitung tiga komponen secara terpisah:

Komponen yang Dihitung:
  • Jam Lembur: Waktu yang melebihi jam kerja standar (17.00 untuk shift pagi).
  • Denda Keterlambatan: Setiap kelipatan 30 menit terlambat dikenakan potongan berjenjang.
  • Status Kehadiran: Hadir, Terlambat, Alpha — ditentukan otomatis tanpa input manual.
// Kalkulasi Jam Lembur Otomatis
=IF(Jam_Keluar > TIME(17,0,0),
    (Jam_Keluar - TIME(17,0,0)) * 24,
    0)

// Denda Keterlambatan Progresif
=IF(Jam_Masuk <= TIME(7,0,0), 0,
  IF(Jam_Masuk <= TIME(7,30,0), 10000,
  IF(Jam_Masuk <= TIME(8,0,0),  25000, 50000)))

3. Desain Keamanan & UX Template

Sebuah sistem otomasi hanya berguna jika tidak mudah dirusak oleh pengguna akhir. Saya menerapkan dua lapisan perlindungan:

🛡️
Data Validation

Input jam dibatasi hanya menerima format HH:MM. Jika admin memasukkan teks sembarang, sistem akan menolak dan menampilkan pesan error khusus.

🔐
Sheet Protection

Seluruh sel yang berisi formula dikunci dengan password. Admin hanya bisa mengedit kolom input, sehingga formula kalkulasi tidak bisa terhapus secara tidak sengaja.

4. Hasil & Dampak Operasional

Template ini dilengkapi Data Validation agar admin HR tidak bisa salah input format jam, dan Sheet Protection pada sel formula agar tidak tidak sengaja terhapus.

0%
