Dasar-Dasar Power Query: Otomasi Data Cleaning Tanpa Formula

Import, transformasi, dan gabungkan data dari berbagai sumber — sekali setup, tinggal klik Refresh setiap bulan. Tidak perlu VBA, tidak perlu formula rumit.

Apa itu Power Query?

Power Query adalah engine transformasi data yang sudah built-in di Excel sejak versi 2016. Fungsi utamanya: mengambil data dari sumber mana saja, membersihkan dan mentransformasinya, lalu memuatnya ke Excel — dan semua langkah yang kamu lakukan direkam secara otomatis sebagai Applied Steps.

Artinya: bulan pertama kamu setup Power Query untuk mengolah laporan penjualan bulanan — import CSV, bersihkan format tanggal, hapus kolom tidak perlu, gabungkan dengan data karyawan. Bulan kedua, cukup ganti file CSV-nya dan klik Refresh. Semua langkah transformasi dijalankan ulang secara otomatis.

Ini yang memisahkan analis yang bekerja cerdas dari yang bekerja keras — Power Query mengotomasi pekerjaan yang biasanya dilakukan manual berulang kali.

💡 Power Query vs Formula vs VBA

Formula Excel bekerja di level sel — satu formula, satu hasil. VBA butuh kemampuan programming. Power Query bekerja di level tabel — satu query, seluruh dataset. Untuk transformasi data yang berulang setiap bulan, Power Query adalah pilihan yang paling efisien dan paling mudah di-maintain oleh orang lain.

Cara Masuk ke Power Query Editor

Ada beberapa cara untuk membuka Power Query tergantung dari mana kamu mulai:

Situasi Cara Masuk
Mulai dari data baru Tab Data → Get Data → pilih sumber
Edit query yang sudah ada Tab Data → Queries & Connections → klik kanan query → Edit
Dari Excel Table Klik sel dalam tabel → Tab Data → From Table/Range
Buka Power Query Manager Tab Data → Get Data → Launch Power Query Editor

Setelah Power Query Editor terbuka, kamu akan melihat tiga area utama: panel Queries di kiri (daftar semua query), area Preview di tengah (tampilan data), dan panel Applied Steps di kanan (rekaman semua langkah transformasi).

💡 Applied Steps adalah Undo yang Permanen

Setiap langkah transformasi yang kamu lakukan di Power Query Editor direkam di Applied Steps. Kamu bisa klik langkah mana saja untuk melihat kondisi data sebelum langkah itu dijalankan — seperti time machine untuk data. Ini juga memudahkan debugging ketika ada transformasi yang menghasilkan hasil yang tidak diharapkan.

Import Data dari Berbagai Sumber

Power Query bisa mengambil data dari hampir semua sumber. Yang paling sering dipakai analis data Indonesia:

Sumber Cara Akses Kelebihan
File CSV/TXT Get Data → From File → From Text/CSV Paling umum, langsung auto-detect delimiter
File Excel lain Get Data → From File → From Workbook Bisa pilih sheet atau named range tertentu
Folder (banyak file) Get Data → From File → From Folder Gabungkan semua file dalam folder sekaligus
Excel Table aktif Tab Data → From Table/Range Query langsung dari data di sheet yang sama
Database (SQL Server, MySQL) Get Data → From Database Query langsung ke database tanpa export

Yang paling powerful untuk pekerjaan bulanan adalah From Folder — misalnya kamu punya folder berisi 12 file laporan bulanan dengan struktur yang sama. Power Query bisa menggabungkan semua file tersebut menjadi satu tabel secara otomatis, termasuk file baru yang ditambahkan ke folder bulan depan.

⚠️ Path File Jangan Dipindah

Power Query menyimpan path absolut ke file sumber. Jika file sumber dipindah ke folder lain, query akan error saat di-Refresh. Selalu simpan file sumber di lokasi yang stabil, atau gunakan relative path dengan From Folder. Jika terpaksa pindah, update path di Data Source Settings.

Transformasi Data Dasar

Ini adalah operasi yang paling sering dilakukan setelah data berhasil di-import. Semuanya bisa dilakukan via klik kanan atau menu Transform tanpa perlu menulis kode apapun.

Operasi Cara Setara dengan
Hapus kolom tidak perlu Klik kanan header kolom → Remove Columns Hapus kolom manual
Ubah tipe data Klik kanan header → Change Type Format Cells + konversi manual
Hapus baris duplikat Home → Remove Rows → Remove Duplicates Data → Remove Duplicates
Filter baris Klik dropdown di header kolom AutoFilter
Trim spasi Transform → Format → Trim =TRIM()
Split kolom Home → Split Column → By Delimiter Text to Columns
Rename kolom Double-click nama kolom Ganti header manual
Pivot/Unpivot Transform → Pivot Column / Unpivot Columns Tidak ada padanannya di Excel biasa

💡 Ubah Tipe Data Selalu Jadi Langkah Pertama

Segera setelah import, ubah tipe data setiap kolom ke tipe yang benar — Date untuk tanggal, Whole Number atau Decimal untuk angka, Text untuk kode dan ID. Power Query kadang menebak tipe data secara salah, terutama untuk kolom yang campur angka dan teks. Tipe data yang salah menyebabkan operasi transformasi berikutnya menghasilkan error yang sulit ditelusuri.

Append vs Merge Query

Dua operasi penggabungan data yang paling penting di Power Query — dan sering tertukar karena namanya tidak intuitif.

Append — Tumpuk Baris

Append menggabungkan dua atau lebih tabel dengan struktur kolom yang sama menjadi satu tabel yang lebih panjang. Analoginya: seperti copy-paste tabel kedua ke bawah tabel pertama.

Kapan dipakai: menggabungkan laporan bulanan yang terpisah (Januari, Februari, Maret) menjadi satu tabel tahunan. Atau menggabungkan data dari beberapa cabang yang punya format kolom sama.

Cara akses: Home → Append Queries → pilih tabel yang ingin digabungkan.

Merge — Gabungkan Kolom dari Tabel Lain

Merge menggabungkan dua tabel berdasarkan kolom kunci yang sama — persis seperti VLOOKUP tapi lebih powerful. Hasilnya adalah tabel yang lebih lebar, bukan lebih panjang.

Kapan dipakai: menambahkan nama karyawan dari tabel HR ke tabel transaksi yang hanya punya ID karyawan. Atau menambahkan nama produk dari tabel master ke tabel penjualan.

Cara akses: Home → Merge Queries → pilih tabel kedua → pilih kolom kunci dari masing-masing tabel → pilih Join Kind.

Operasi Hasil Analogi Excel
Append Tabel lebih panjang (lebih banyak baris) Copy-paste ke bawah
Merge (Left Join) Tabel lebih lebar (lebih banyak kolom) VLOOKUP
Merge (Inner Join) Hanya baris yang ada di kedua tabel VLOOKUP tanpa IFERROR
Merge (Full Outer) Semua baris dari kedua tabel Tidak ada padanannya

Load ke Excel & Refresh Otomatis

Setelah semua transformasi selesai, ada dua cara untuk memuat hasil ke Excel:

  • Close & Load — muat ke sheet baru sebagai tabel Excel biasa. Ini pilihan paling umum.
  • Close & Load To — pilih mau dimuat ke mana: sheet baru, sheet yang sudah ada (di sel tertentu), atau hanya sebagai Connection tanpa menampilkan data (berguna jika query ini hanya dipakai sebagai sumber untuk query lain atau PivotTable).

Setelah data dimuat, cara me-Refresh:

  • Klik kanan tabel hasil → Refresh
  • Tab Data → Refresh All untuk refresh semua query sekaligus
  • Shortcut: Ctrl+Alt+F5 untuk Refresh All

💡 Setup Refresh Otomatis

Di tab Data → Queries & Connections → klik kanan query → Properties → centang "Refresh every X minutes" atau "Refresh data when opening the file". Dengan opsi kedua, setiap kali file Excel dibuka, data langsung diperbarui dari sumber — ideal untuk dashboard yang dibuka setiap pagi.

⚠️ Refresh Membutuhkan Akses ke Sumber Data

Jika file Excel dikirim ke orang lain dan mereka mencoba Refresh, Excel akan mencari file sumber di path yang sama di komputer mereka. Jika path tidak ada, Refresh akan error. Untuk file yang dibagikan, pertimbangkan untuk menyertakan file sumber dalam folder yang sama atau gunakan SharePoint/OneDrive sebagai sumber data.
