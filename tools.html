Dataset Generator

Seringkali kita ingin berlatih Excel, tetapi tidak punya data mentah untuk diolah. Fitur ini akan membuatkan ratusan baris data acak yang terlihat sangat nyata (seperti nama karyawan, gaji, atau laporan penjualan) hanya dengan satu klik! Anda bisa mengunduhnya sebagai file CSV lalu membukanya di Excel untuk berlatih.

🚀 Kekuatan Penuh: Hasilkan hingga 10.000 baris data dalam 1 detik!
⚡

Fitur Analis Lanjutan

Data sengaja disisipi nilai kosong (NULL) dan format berantakan. Cocok untuk latihan Data Cleaning.

Hasilkan file Master Produk & Data Transaksi terpisah. Sempurna untuk berlatih fungsi VLOOKUP.

Tambahkan kolom Metode Pembayaran, Harga Modal (COGS), Tipe Pelanggan, dan Status Transaksi.

Data menggunakan pemisah Titik Koma (;) agar langsung rapi (menjadi kolom) saat dibuka di Excel versi Indonesia.
